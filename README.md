# CREATIVEMATRIX.AI

A high-performance, futuristic, free-learning ecosystem built for the **SAYEMATRIX** community.

CREATIVEMATRIX.AI is designed around the intersection of **AI, Design, Creativity, Psychology, Productivity, and Digital Systems** — giving learners practical tools and structured knowledge without unnecessary barriers.

---

## Features

* **The Matrix Aesthetic**
  A high-contrast **Cyber-Noir** interface featuring Neon Purple and Matrix Green visual accents.

* **Learning Hub**
  25+ structured masterclass modules covering AI artistry, creative psychology, productivity, and digital systems.

* **One-Click PDF Export**
  Download lessons as professionally formatted, branded PDFs for offline learning.

* **Matrix Quick-Tools**
  AI-powered prompt engineering and content workflow generation using Google Gemini.

* **Hustlers' Circle**
  Community integration with the SAYEMATRIX Telegram and Discord ecosystem.

---

## Tech Stack

* **React 19** — Modern UI component architecture
* **Tailwind CSS** — Utility-first styling with custom visual configurations
* **Lucide React** — Interface iconography
* **jsPDF** — Client-side PDF generation
* **Google Gemini API** — AI-powered creative tools
* **ESM.sh** — Buildless ES module delivery

## Development

### 1. Clone the Repository

```bash
git clone <YOUR_REPOSITORY_URL>
cd CREATIVEMATRIX.AI
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Configure Environment Variables

Create a `.env` file and configure the required API credentials.

```env
API_KEY=your_gemini_api_key
```

**Never commit `.env` files or private API keys to GitHub.**

Make sure `.env` is included in `.gitignore`.

### 4. Start Development

```bash
npm run dev
```

## Netlify Deployment

This project is optimized for deployment on **Netlify**.

### Deployment Steps

1. Connect the GitHub/GitLab repository to Netlify.
2. Configure the build settings.
3. Add the required environment variables.
4. Deploy the project.
5. Verify SPA routing and API functionality.

### Environment Variables

Configure:

```text

```

If an API key is accidentally exposed, **revoke and rotate it immediately**.
